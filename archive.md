# Archivio — Storico delle decisioni

> Riceve ciò che esce da un `memory.md` perché sostituito o superato: decisioni cambiate, obiettivi chiusi, stati che non valgono più. Si aggiunge in cima, non si riscrive mai il passato.

Formato di una voce:

```
## AAAA-MM-GG — [titolo breve dell'evento]

[Cosa valeva prima, cosa vale adesso, perché è cambiato. Il contenuto vecchio si copia qui integralmente prima di essere sovrascritto in memory.md.]
```
